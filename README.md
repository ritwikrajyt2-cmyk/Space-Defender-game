# 🚀 Space Defender Game

A futuristic space shooting game developed using **Python and Pygame**.

## 🎮 About the Game

Space Defender is a 2D space shooting game in which the player controls a spacecraft, destroys incoming enemies, collects power-ups, and tries to achieve the highest score.

The game features a futuristic space environment, animated stars, laser shooting, enemy spacecraft, sound effects, and a power-up system.

## ✨ Features

* 🚀 Player spacecraft with smooth movement
* 👾 Enemy spacecraft
* 🔫 Laser shooting system
* ⭐ Score system
* ❤️ Three player lives
* ⚡ Power-up system
* 🎵 Background music and sound effects
* 🌌 Animated space background
* 🖥️ Fullscreen mode
* 🔄 Restart option after Game Over

## 🕹️ Controls

| Key           | Action               |
| ------------- | -------------------- |
| W / A / S / D | Move spacecraft      |
| Arrow Keys    | Move spacecraft      |
| Space         | Fire laser           |
| Enter         | Start / Restart game |
| F11           | Toggle fullscreen    |
| Esc           | Exit game            |

## 📥 Installation

### 1. Clone the repository

```bash
git clone https://github.com/ritwikrajyt2-cmyk/Space-Defender-game.git
```

### 2. Open the project folder

```bash
cd Space-Defender-game
```

### 3. Install Pygame

```bash
pip install pygame
```

### 4. Run the game

```bash
python Game.py
```

## 🎯 Objective

Destroy enemy spacecraft using lasers, collect power-ups, and survive as long as possible to achieve a high score.
